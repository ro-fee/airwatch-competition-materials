## 内容

- `software/`：2026-10-03 本机项目的相关源码、测试、训练配置、数据来源元信息和文档快照。
- `evidence/a800-v2/`：A800 正式实验的选型、校准、冻结契约、成员级预测、测试指标、基准和失败记录；本地验收报告也在此目录。
- `reference/`：Word 任务书与早期报告的文本摘录，供云端阅读；不能把早期状态当成当前状态。
- `CURRENT_FACTS.md`、`FACTS.json`：由回传证据生成的当前事实与引用入口。

本仓库是**资料与源码快照，不是完整软件发行包或可直接复现训练的全量数据包**。原始数据、模型权重、训练优化器状态、安装缓存、详细评估分片、窗口级大 CSV 和本机个人配置均未上传。完整结果仍保存在项目本地归档。

`software/docs/` 中部分旧链接指向被排除的本地数据或二进制文件；dot 应使用本仓库根目录的事实与证据索引，不将缺失链接解释为实验已复现。冻结契约仍保留原始权重哈希，未为适应资料快照而改写。
