# VTI_DroneSET 数据登记

本目录保存 VTI_DroneSET V1 的本地数据治理记录。数据来自 Mendeley Data，DOI 为 `10.17632/s6tgnnp5n2.1`，许可证为 CC BY 4.0。

- `source/VTI_DroneSET.7z`：官方原始归档，只读保存；官方与本地 SHA-256 均为 `524e038f6577729778dbd31910076880e296b24e3047e4976d7c74a6b7bc9a3a`。
- `download-log.json`：固定版本、来源、下载时间、字节数、校验结果与当前准入状态。
- `archive-inventory.json`：外层归档的 6 个成员名和声明大小，以及密码门状态。

Windows `bsdtar` 不支持该归档的加密方式；一次失败尝试产生的不可用临时文件已经删除，`packages/` 在取得作者密码前应保持为空。

当前状态：作者回复后提供的密码已于 2026-09-29 验证成功，外层解密与完整性检查通过。最新内容审计见 `content-audit-v2.json`；原下载和密码申请记录保留为历史证据。密码未写入仓库或上传包。

已审计 6 个内层归档、全部 50 个预处理 MAT 头和 4 个 DNN CSV，并抽查两个频段各一个原始 MAT 元数据。原始采样间隔对应 150 MS/s，当前 KU Leuven 冻结模型要求 100 MS/s，预处理矩阵与多无人机标签也未经等价适配。因此当前准入结论为 `blocked_incompatible_representation`，只作外部来源审计，不用于训练、选择或宣称外部测试性能。A800 上传包携带原始归档及审计，不携带密码。

原先规划的取得密码后审计顺序如下；本轮实际检查范围与结果以新版审计 JSON 为准：

1. 用支持 7z AES 的工具验证并提取 6 个内层归档，保存逐包 SHA-256；
2. 优先审计体积较小的 `02_DNN_DATA_*` 与 `01_PP_RF_SNIMCI_*`，确认矩阵方向、标签行、预处理和录制边界；
3. 再抽样核验 `00_RAW_RF_SNIMCI_*` 的 MATLAB 变量、采样率、中心频率和 BUI 文件名；
4. 按原始录制构造只用于独立外部验证的清单，禁止把聚合 CSV 随机切列后跨集合使用；
5. 冻结标签映射与协议后，才允许读取噪声增强 TCN 候选并生成外部验证证据。

官方说明记录的数据边界：2.4/5.8 GHz 各 25 条录制，共 50 条；每条约 450 ms；采样率 150 MSamples/s；瞬时带宽 110 MHz；包含单机、双机和三机场景，环境为室内实验室。以上是数据作者描述，不等于本地内容已经验证。
