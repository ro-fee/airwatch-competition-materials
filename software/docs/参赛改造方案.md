# 空域电波哨兵参赛改造方案

## 1. 主题与价值主张

主题：面向低空无人机的端侧智能频谱感知与未知信号预警。

一句话价值主张：在不依赖云端和主动发射的条件下，通过被动接收射频信号，在普通电脑或边缘设备上完成无人机检测、类型/状态识别、未知设备告警和事件留痕。

目标用户包括校园与园区安防人员、低空基础设施运维人员、科研教学团队和获得授权的频谱监测人员。系统只面向授权环境下的被动接收与离线分析，不包含干扰、压制、欺骗或未经授权的监听能力。

## 2. 参赛版产品闭环

### 页面一：频谱态势

- 导入 `.npy`、公开数据转换格式和演示清单。
- 回放时域、频谱和动态瀑布。
- 展示采样率、中心频率、来源、估计 SNR 和频谱占用。
- 在时间轴或瀑布图上标记检测与告警事件。

### 页面二：无人机智能识别

- 输出无人机存在概率。
- 输出设备或无人机类型、工作状态及各任务置信度。
- 输出已知/未知判断和开放集分数。
- 支持单文件、批量文件和事件结果表。

### 页面三：鲁棒性实验室

- 用可控噪声、频偏、幅度衰落和可选多径构造难例。
- 对比扰动前后波形、频谱、识别和开放集结果。
- 保留 GAN 作为可选研究模块，但不使用不真实的 FID 或扩充收益。

### 页面四：端侧部署评测

- 对比教师模型与轻量学生模型的真实指标。
- 展示参数量、模型大小、P50/P95 时延、吞吐和峰值内存。
- 所有数值从测试产物读取，不允许界面硬编码。

## 3. 数据方案

### 主数据集

优先使用 DroneRF 作为第一条可复现数据链，完成来源、许可、下载、校验、转换、元数据和划分审计。

### 第二数据源

已选择 VTI_DroneSET V1 作为优先外部候选。官方 6.28 GB 归档的字节数、SHA-256、版本与 CC BY 4.0 许可已核验；作者回复后提供的密码已验证。本轮元数据审计确认原始采样间隔对应 150 MS/s，预处理 Data 为 [670,2048]，DNN CSV 为 2051 行的聚合矩阵。它与当前 KU Leuven 100 MS/s IQ 协议不等价，故暂标记 `blocked_incompatible_representation`，不输出该来源的模型性能。

后续如需使用 VTI，应先单独冻结并验证采样率、表示及标签适配协议，保留 BUI 录制边界，不对聚合 CSV 随机切列制造跨集合泄漏。本轮仅保存原始归档与实际审计，不将其加入训练、选型或阈值校准。详细审计范围见 `datasets/uav/vti_droneset/content-audit-v2.json`。

KU Leuven `Drone RF Dataset` V1.0 已作为第三候选完成官方元数据审计：固定 DOI `10.48804/HZRVNZ`、CC BY-NC 4.0、19 个公开文件，总计 46,696,930,089 字节；官方 README 和两个 MATLAB 脚本已按官方 MD5 验证。首个 `SJRC_pro.zip` 已下载并通过官方 MD5。MATLAB v7.3 分块读取器已通过 8 项边界测试和真实窗口验收；51 个 MAT 成员随后全部在 ZIP 内完成 HDF5 元数据检查和成员级 SHA-256 计算，均为 `1×10,000,000` 复数双精度数据。按固定种子 `20260908` 生成了 1,632 行录制内互不重叠的 4,096 点窗口计划，并用哈希索引绑定清单、计划和验证报告。进一步核查 DE-FEND 论文后，确认 `SJRC pro` 的信号类型为 RC，且在原论文协议中属于 unknown source；因此本项目把整个归档预注册为 `external_unknown_test`，禁止参与训练、验证、阈值选择和模型选择。官方资料仍未证明各 MAT 是独立物理采集会话，所以源清单继续保持 `split=unassigned`，正式结果须按 MAT 成员聚合后再汇总整个归档。该数据是 100 MS/s、2.44 GHz 复数 I/Q；DroneRF 则是 40 MS/s 时域实幅值的 2.4 GHz 下/上半带。两源统一派生表示和兼容模型冻结前不运行外部测试。

DroneRF 原始论文复核纠正了项目早期语义：L/H 是 40 MS/s 时域实幅值的 2.4 GHz 下/上半带，不是独立的 2.4/5.8 GHz 通道。训练链现已能显式选择下半带并把该语义写入数据身份；KU Leuven 则是 100 MS/s、2.44 GHz 复数 I/Q。必须先冻结一套两源一致的派生表示，当前仍不运行跨来源测试。兼容性纠正记录位于 `datasets/uav/ku_leuven_drone_rf/compatibility-semantics-correction.json`。

为避免模型把采集设备差异误当“未知”，开放集主路线改为 KU Leuven 数据集内部的同硬件协议：论文 Table I 中的 Frysky、Spektrum DX4e RC、DJI Mini 2 RC 作为首轮三个已知源，Table II 中的 NineEagles、WlToys、Q205、SJRC Pro 四个源整包仅用于冻结后的未知评估。三个已知源官方包均已完成字节数、MD5 与 SHA-256 校验；共 193 个 MAT 成员均为 `1×10,000,000` 复数 IQ，成员哈希完整，并生成 6,176 个不重叠窗口计划。冻结划分已将 115/24/24 个成员分配到训练/验证/测试，在两个边界各丢弃 5 个完整 MAT，共 30 个 guard。该方案降低相邻样本泄漏，但官方未提供物理会话映射，不宣称跨会话泛化。固定预处理 `ku-leuven-iq-dc-rms-v1` 已在三类各一个已注册训练窗口上通过真实数据验收，仅做逐通道去直流和逐窗口复数 RMS 归一化，不使用跨窗口、验证或测试统计。成员级聚合与训练配置冻结前不启动训练。预注册草案位于 `training/configs/ku_leuven_in_domain_known_unknown_protocol_v1.json`。DroneRF 继续作为独立同源基线，跨数据源测试降为明确标注域偏移的次要实验。

成员级聚合已冻结为 32 个窗口 softmax 概率向量均值，窗口不足或标签混合时拒绝评估；开放集阈值只允许使用已知验证录制并固定 95% 目标接受率。本机 RTX 4060 曾按单独的开发协议完成 TCN 与 ResNet18 各 3 个固定种子的 6 次训练，当时 known test 与 unknown 均未读取。六个最佳检查点的 24 成员验证 Macro-F1 均为 `1.0`，表明聚合指标已在小验证集上饱和，不能作为参赛测试成绩；机器生成的事后诊断中，TCN 最佳检查点窗口级 Macro-F1 为 `0.7750±0.0229`，高于 ResNet18 的 `0.6632±0.0651`，且 TCN 参数量更少，因此仅将 TCN 作为下一轮本机稳定性/受控扰动开发候选。旧 A800 V1 配置与 dry-run 进度保持原样；A800 V2 按独立 12-run 协议执行，2026-10-03 已收到服务器训练和冻结评估结果。归档与本地验收见《A800训练结果归档与接入说明》。后续接入应遵循已选中的 A 组 TCN 和冻结阈值，保留新结构未达到改进门槛的负结果及未知误接受限制，不能在看到保留测试后重新选型或调阈值。

KU Leuven 强噪声 V2 的综合开发验收已通过，但 `-5 dB` 分档仍失败，不将其包装为低信噪比突破。为尽早形成可演示的纵向闭环，软件最初接入 V2 `seed=20260910` 开发候选：运行契约校验检查点、配置、模型定义、预处理和推理代码的 SHA-256，Qt 任务在 CPU 后台执行并提供进度、取消、错误传递与清理。当时输出只包含三已知源类别、均值 softmax 置信度和模型版本；已知/未知固定显示“未评估”。候选种子是根据重复使用的 40 个开发条件事后选出，该软件链路只是开发演示，不是独立泛化证据。

后续的 V3 只改变检查点选择，将 `-5 dB` 平均从 V2 的 `0.3253` 提高到 `0.5854`，但最差种子/重复仍为 `0.1818`，按预注册验收失败。V4 保留 V3 选择规则，只把 AWGN 分支内 `-5 dB` 抽样权重从 `1/6` 提高到 `1/2`；相对 V3，`-5 dB` 均值达到 `0.8569`、最差值达到 `0.6308`，clean 保持 `1.0`，`0/5 dB` 和多径守门同时通过。软件默认开发模型已换为 V4 `seed=20260910`，但仍固定显示未知拒识“未评估”。所有结果都复用同一 24 成员开发验证集和合成扰动，不是独立泛化、物理 SNR 或参赛测试证据。

### 统一样本元数据

每个样本至少记录：

- `file_id`、`recording_id`、`source` 和原始文件校验值。
- `device_id`、`drone_type`、`operation_mode` 和已知/未知标签。
- `sample_rate`、中心频率、SNR 或噪声等级。
- `split`、切片起点、切片长度和预处理版本。

训练、验证和测试必须按录制单元、设备或采集日期分组划分，禁止同一原始录制的相邻切片跨集合泄漏。

## 4. 算法主线

### 4.1 可复现基线

先使用统一数据与评估协议完成 1D CNN、ResNet18 和 TCN 三个基线。基线冻结前不开发复杂创新模型。

为跨来源开放集实验准备的单子带切片已于 2026-09-09 接入：`DroneRFWindowDataset` 可在不改写源产物的前提下只选择原始第 0 通道（2.4 GHz 下半带），并把 `band_selection`、源通道索引、输入通道数和时域实幅值语义写入数据身份；CNN、ResNet18、TCN 也会拒绝与配置不一致的通道数。本机 RTX 4060 Laptop GPU 已完成 1 轮工程冒烟训练，验证了 5,152/1,056/1,056 个窗口的训练、验证和保留测试边界以及检查点写入；冒烟过程没有读取测试集，单轮指标不作为参赛性能。对应配置和机器证据位于 `training/configs/dronerf_tcn_low24_local_smoke_v1.json` 与 `artifacts/evidence/uav/smoke/`。A800 正式配置位于 `training/configs/dronerf_tcn_low24_a800_formal_v1.json`，在统一派生表示与协议冻结前只允许 dry-run，不启动正式跨来源训练。

### 4.2 双分支多任务模型

- 时域分支：轻量 1D CNN 或 TCN，提取瞬态、相位和时序结构。
- 时频分支：对 STFT 谱图使用轻量 2D CNN。
- 融合模块：对两个分支进行拼接、加权或门控融合。
- 多任务输出：无人机检测、类型识别和工作状态识别。

首轮冻结消融已于 2026-09-08 完成，固定随机种子为 `20260908`，模型选择指标为验证集录音级类型 Macro-F1。四个预注册变体的结果如下；测试集只在各变体验证最优检查点冻结后评估一次，没有用于修改结构或参数。

| 变体 | 验证录音 Macro-F1 | 测试录音 Macro-F1 | 结论 |
|---|---:|---:|---|
| 仅 STFT 频域分支 | 0.6408 | 0.7099 | 频域单独不足以承担主任务 |
| TCN + STFT 直接拼接 | 0.8750 | 0.8750 | 时频互补有效 |
| TCN + STFT 自适应门控 | **0.9791** | **0.8996** | 消融内验证最优；时间分支平均权重 0.8468 |
| 自适应门控 + 存在性辅助头 | 0.9161 | 0.8448 | 存在性测试录音 Macro-F1 0.9455，但损害类型主任务 |

同种子 TCN 基线的测试录音 Macro-F1 为 0.9365，高于当前双分支的 0.8996。因此本轮结果只证明分支互补和门控可学习，不证明整体超越基线。下一版应保留 TCN 主干，把频域信息用于低 SNR 条件专家或后验融合，并隔离存在性辅助梯度，再以冻结协议复验；在此之前不将双分支包装为最终主模型。

机器生成的完整证据见 `artifacts/evidence/uav/dronerf_dual_branch_ablation_seed20260908_v1_summary.json` 和同名 CSV。当前仍是单随机种子、单一公开数据源、录制级划分结果，不能外推为跨设备或真实部署性能。

### 4.3 低 SNR 感知

使用估计 SNR 或噪声等级作为辅助输入，控制分支融合权重或特征调制。需要与固定融合方案在相同测试协议下比较。

首轮压力测试已冻结 `-20、-15、-10、-5、0、5、10、15、20 dB` 和 clean 条件，并对同种子 TCN 与自适应双分支执行相同的确定性加噪。每个条件包含 1,056 个窗口、33 条录音；录音级 Macro-F1 使用 2,000 次按类别分层的配对 bootstrap 计算 95% 区间。

| 相对加噪条件 | TCN 录音 Macro-F1 | 自适应双分支 | 双分支−TCN |
|---:|---:|---:|---:|
| -20～-5 dB | 均为 0.1333 | 均为 0.1333 | 0 |
| 0 dB | 0.2614 | 0.1333 | -0.1280 |
| 5 dB | **0.9040** | 0.3773 | **-0.5268**，95% CI `[-0.5844,-0.4579]` |
| 10 dB | **0.9365** | 0.7841 | **-0.1524**，95% CI `[-0.2910,-0.0296]` |
| 20 dB | **0.9365** | 0.8996 | -0.0369 |

结果不支持现有双分支的低 SNR 优势。在 `5 dB`，其 82.29% 窗口预测塌缩到 Bebop，AR 与 Phantom 录音级 F1 均为 0。下一轮优先用训练集确定性噪声增强训练 TCN，并仅使用验证集选择增强范围；只有增强模型在冻结测试协议下获得可重复改善且 clean 性能无明显退化，才进入候选主模型。

噪声增强 TCN 已按上述方向完成首轮开发。训练窗口以 `25% clean + 75% 确定性 AWGN` 混合，噪声档位为 `0/5/10/15/20 dB`；检查点只按同档验证集平均录音 Macro-F1 选择，并设置 clean 最多下降 3 个百分点的守门线。最佳检查点来自第 3 轮：clean 保持 `0.9365`，`0 dB` 从原 TCN 的 `0.1333` 提升到 `0.4046`，差值 95% CI 为 `[0.1455,0.3834]`；`5 dB` 从 `0.8786` 提升到 `0.9365`；`0～10 dB` 三档平均提升 `0.1097`。由于候选正是在这些验证条件上选出，区间只作开发描述；此前测试集已用于失败诊断，本候选不再读取该测试集，最终结论等待第二数据源或新的独立留出集。

完整证据与曲线位于 `artifacts/evidence/uav/dronerf_added_noise_robustness_seed20260908_v1.*`，失败分析位于同目录的 `_failure_analysis.json/.csv`。上述 dB 表示归一化已采集窗口与新增噪声的经验功率比；DroneRF 原始采集噪声未知，因此不能称为校准物理 SNR。

噪声增强训练证据位于 `artifacts/evidence/uav/dronerf_tcn_noise_augmented_seed20260908_validation_v1_training.json`，验证对比位于 `artifacts/evidence/uav/dronerf_tcn_noise_augmented_validation_comparison_v1.*`。

### 4.4 开放集识别

先建立最大 Softmax 概率基线，再比较 Energy Score 或原型距离。阈值只能使用验证集确定，测试集不得参与调参。

首版已知样本校准协议已于 2026-09-08 冻结并执行，主模型为当前三随机种子基线中表现最稳的 TCN `seed=20260908` 检查点。类别原型使用 5,152 个训练窗口拟合；MSP、负 Energy 和余弦原型分数按录音聚合，只使用 1,056 个验证窗口对应的 33 条录音校准。目标已知接受率为 95%；由于录音数离散，三个方法均接受 32/33 条验证录音，即 96.97%。冻结阈值如下：

| 方法 | 已知性方向 | 冻结阈值 | 验证已知接受率 |
|---|---|---:|---:|
| 最大 Softmax 概率 | 越高越像已知 | 0.617740 | 96.97% |
| 负 Energy（T=1） | 越高越像已知 | 2.583423 | 96.97% |
| 训练类原型余弦相似度 | 越高越像已知 | 0.829687 | 96.97% |

本轮代码不会构建或读取测试集，证据中明确记录 `test_data_used=false`、`unknown_data_used=false`。这些数值只证明阈值校准链已建立，不代表未知检测效果。三个阈值必须保持冻结，待经过许可、格式和录制边界审计的第二数据源到位后，才能一次性报告 AUROC、FPR95、未知拒识率与已知准确率；不得依据外部测试结果重新选择方法或阈值。

校准证据位于 `artifacts/evidence/uav/dronerf_tcn_open_set_calibration_v1.json`，逐录音分数位于同目录的 `_scores.csv`，冻结协议位于 `training/configs/dronerf_tcn_open_set_calibration_protocol_v1.json`。

### 4.5 端侧轻量化

使用主模型作为教师，训练轻量学生模型并进行知识蒸馏。对比只蒸馏训练与普通训练，报告性能损失、速度收益和模型大小。

## 5. 统一评估指标

| 能力 | 主要指标 | 辅助证据 |
|---|---|---|
| 无人机检测 | Macro-F1、Recall、Precision | 混淆矩阵、失败案例 |
| 类型/状态识别 | Accuracy、Macro-F1 | 分类别指标、混淆矩阵 |
| 低 SNR 鲁棒性 | 指标-SNR 曲线 | 每个 SNR 的样本量与置信区间 |
| 开放集 | AUROC、FPR95、未知拒识率 | 已知准确率、阈值来源 |
| 端侧性能 | P50/P95 时延、吞吐 | 参数量、模型大小、峰值内存 |
| 软件质量 | 主流程成功率、稳定运行时间 | 异常输入、安装与重复演示记录 |

所有主结果至少固定随机种子并保存配置、日志、权重、原始指标文件和绘图脚本。条件允许时报告多随机种子均值与 95% 置信区间。

4. 双分支、多任务、低 SNR、开放集和轻量模型。
5. 四页软件闭环与后台推理。
6. 主实验、消融、跨数据源、失败案例和端侧基准。
