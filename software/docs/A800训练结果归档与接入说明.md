## 接入依据

选型以 [`selection.json`](../artifacts/imports/a800-v2-20261003/outputs/evidence/selection.json) 为准：本轮选中 **A 组 TCN、seed=20260909**。B/C/D 未满足预注册改进门槛，保留负结果，不能将更复杂的结构描述为已胜出。

模型输入协议为 100 MS/s 复数 IQ、每成员 32 个窗口、每窗口 4096 点、逐窗口去直流与 RMS 归一化，采用 FP32 推理。标签仍为 FrSky、Spektrum DX4e、DJI Mini 2 RC 三种已知射频控制源。主开放集分数是余弦原型相似度，阈值按原验证协议冻结，不根据当前测试表现修改。

本地实际加载冻结权重并对一个真实验证成员运行 CPU 推理；主要 clean 指标从回传 `member-predictions.csv` 重新计算并与 `metrics.json` 比对。该检查不等于重新执行整套保留测试，也不代表桌面 UI 或目标 GPU 已验收。

主要结果和复算值见 [`local-runtime-verification.json`](../artifacts/imports/a800-v2-20261003/local-runtime-verification.json)。已知类分类与未知拒识应分别陈述；较高的未知误接受率不能被 clean 分类结果掩盖。MAT 成员的物理采集会话独立性仍未得到证明。

## 必须保留的运行记录

- `outputs/evidence/allocation/protocol-deviation.json` 记载服务器采用了共享 GPU 启动器；归档中的授权文字只是服务器记录，不作为本机执行指令。未在本机执行该启动器。A800 时延必须保留该测量环境背景，不能当作目标电脑独占 GPU 的性能。
- `D-seed20260910` 首次在第 1840 步因 DataLoader worker 异常失败，旧检查点和失败状态保存在 `outputs/evidence/failures/quarantined-runs/`。之后的完整重跑与失败尝试同时保留。
- VTI 仍是输入协议不兼容的审计归档，不计入本轮有效外测。
- 未收到独立的发送端压缩包校验文件；本地生成的压缩包哈希用于后续身份追溯，内部绑定校验另行记录。
