## 二、最推荐先测的 5 个案例

### 案例 1：单频正弦波——检查频谱峰值和采样率

**文件**：`data/ui_manual_cases/01_single_tone_6000Hz.npy`

**如何使用**：

1. 打开软件，进入“主页/频谱态势”；
2. 点击打开文件，选择该文件；
3. 采样率填写 `48000 Hz`；
4. 查看时域图、频谱图和静态时频图；
5. 再把采样率改为 `96000 Hz` 重画一次。

**正确现象**：

- 时域图是规则的正弦波；
- 采样率为 48000 Hz 时，频谱主峰应在约 `6000 Hz`；
- 时频图应显示一条水平亮线，位置约为 6000 Hz；
- 改成 96000 Hz 后，波形点数不应凭空改变，但频率轴的显示范围应改变；
- 不应把 6000 Hz 显示成固定的 16000 Hz 或其他写死的值。

**主要检查的问题**：频率轴是否使用当前采样率、频谱峰值是否正确、重绘是否清理旧图。

**参考图**：[01_single_tone_6000Hz.png](./ui_manual_cases/01_single_tone_6000Hz.png)

### 案例 2：线性扫频——检查时频图方向

**文件**：`data/ui_manual_cases/02_rising_chirp_2k_to_14k.npy`

**如何使用**：

1. 在主页打开该文件；
2. 采样率填写 `48000 Hz`；
3. 打开静态时频图；
4. 如果软件支持窗口长度，先使用默认值，再改一个合法值重画。

**正确现象**：

- 时频图中应该是一条从左下向右上的亮色斜线；
- 起始频率约为 `2000 Hz`，结束频率约为 `14000 Hz`；
- 不能出现从右上向左下的反向斜线；
- 横轴应是时间，纵轴应是频率 Hz；
- 图像不应上下颠倒，频率 0 应靠近底部。

**主要检查的问题**：时频矩阵方向、时间轴/频率轴映射、采样率和图像上下方向。

**参考图**：[02_rising_chirp_2k_to_14k.png](./ui_manual_cases/02_rising_chirp_2k_to_14k.png)

### 案例 3：周期脉冲——检查波形和瀑布图中的突发信号

**文件**：`data/ui_manual_cases/03_periodic_pulses.npy`

**如何使用**：

1. 在主页打开该文件；
2. 采样率填写 `48000 Hz`；
3. 先看时域图；
4. 再进入动态瀑布图，点击播放、暂停、继续、停止、重新播放；
5. 切换到其他页面后再返回主页。

**正确现象**：

- 时域图中应看到间隔大致相同的矩形脉冲；
- 瀑布图中应看到周期性出现的竖向亮条；
- 点击暂停后帧号应保持；
- 点击继续后帧号继续推进；
- 点击停止后状态应变为已停止，不能继续自动推进；
- 点击重新播放应从第一帧重新开始；
- 切换页面不应弹出绘图失败对话框，也不应出现多个计时器叠加加速。

**主要检查的问题**：动态播放生命周期、暂停/继续/停止/重播、页面切换和 QTimer 清理。

**参考图**：[03_periodic_pulses.png](./ui_manual_cases/03_periodic_pulses.png)

### 案例 4：复数 IQ 的 QPSK——检查 I/Q 波形和星座图

**文件**：`data/ui_manual_cases/04_qpsk_iq.npy`

**如何使用**：

1. 在主页或信号生成/分析相关入口加载该 `.npy`；
2. 如果有“星座图”入口，选择星座图；
3. 如果界面有“复数 IQ/实信号”切换，选择复数 IQ；
4. 再切换回波形和频谱。

**正确现象**：

- 软件应识别为一维复数 IQ，而不是普通一维实信号；
- I 和 Q 应该都有波形；
- 星座图应聚集成四个斜着分布的点簇，中心大致位于 `(±0.707, ±0.707)`；
- 星座图横纵坐标都应有意义，不能只显示一条线；
- 切换回波形后，星座图散点应清除，不应残留在波形图上。

**主要检查的问题**：复数输入识别、I/Q 通道、星座图几何关系、图形模式清理。

**参考图**：[04_qpsk_iq.png](./ui_manual_cases/04_qpsk_iq.png)、[04_qpsk_iq_constellation.png](./ui_manual_cases/04_qpsk_iq_constellation.png)

### 案例 5：二维双通道 IQ——检查 `(2, N)` 输入

**文件**：`data/ui_manual_cases/05_two_channel_iq.npy`

**如何使用**：

1. 在主页加载该文件；
2. 选择 IQ/双通道显示；
3. 分别查看波形、频谱、时频图和星座图；
4. 再打开案例 4，对比两者的图形。

**正确现象**：

- 软件应把第一行当作 I、第二行当作 Q；
- 案例 4 和案例 5 的星座图形状应基本一致；
- 不能把第二个通道丢掉；
- 不能把二维数组直接当成一条错误的长波形；
- 重新打开新文件后，旧文件的图形不能残留。

**主要检查的问题**：二维通道维度判断、IQ 保真、文件切换和旧图清理。

**参考图**：[05_two_channel_iq.png](./ui_manual_cases/05_two_channel_iq.png)

## 三、异常输入案例：重点看提示是否诚实

### 案例 6：全零输入——应该被质量门拒绝

**文件**：`data/ui_manual_cases/06_all_zero_rejected.npy`

**使用位置**：优先在“轴承检测”页面加载；也可以在无人机输入/预览页面加载。

**正确现象**：

- 软件可以显示一条位于 0 的平线，或者明确提示信号没有变化；
- 质量状态应为“拒绝/不可诊断”或同等含义；
- 不应该显示一个看起来很确定的故障类别、无人机类别或置信度；
- 不应崩溃，也不应弹出 Python 堆栈。

**检查问题**：质量门、错误提示、禁止坏输入继续推理。

### 案例 7：NaN 输入——应该明确提示数据异常

**文件**：`data/ui_manual_cases/07_nan_rejected.npy`

**使用位置**：轴承检测、无人机输入或主页打开文件。

**正确现象**：

- 软件应提示信号包含非法数值或无法用于分析；
- 质量状态应为拒绝；
- 不应出现全黑、全白或坐标轴无限放大的假图；
- 不应输出模型类别和置信度。

**检查问题**：NaN/Inf 检查、异常路径、旧图是否清除。

### 案例 8：过短信号——应该提示长度不够

**文件**：`data/ui_manual_cases/08_too_short.npy`

**使用位置**：轴承检测或无人机输入页面。

**正确现象**：

- 软件应提示“信号太短，无法完成当前分析/诊断”；
- 不应为了凑长度自动复制或填充后给出正常诊断结果；
- 不应卡死；
- 上一次成功分析的结果不应继续留在页面上冒充本次结果。

**检查问题**：最小长度校验、异常提示、结果清空。

## 六、如何判断“图像到底对不对”

不要要求软件截图和参考 PNG 每个像素完全一样。不同窗口大小、颜色主题、字体、绘图后端和分辨率都会造成外观差异。人工判断重点是：

1. **形状对不对**：单频是水平线，扫频是斜线，脉冲是周期亮条；
2. **方向对不对**：时间从左到右，频率从下到上；
3. **数值对不对**：6000 Hz 峰值、扫频起止频率和采样率对应；
4. **通道对不对**：I/Q 没有丢失或互换；
5. **状态对不对**：暂停真的停，取消不是失败，拒绝不是故障分类；
6. **生命周期对不对**：打开新文件、切换图形和返回页面后没有旧内容残留。
