# 项目文档索引

本目录是项目文字材料的统一入口。当前项目保留“智能信号处理原型验证系统”的历史能力，并以参加全球校园人工智能算法精英大赛为目标，改造为“空域电波哨兵——面向低空无人机的端侧智能频谱感知与未知信号预警平台”。

## 建议阅读顺序

1. [项目说明](项目说明.md)：了解项目领域、现有功能、技术结构、可信边界和参赛定位。
2. [参赛改造方案](参赛改造方案.md)：了解目标用户、核心场景、算法主线、产品闭环和验收指标。
3. [开发与验收规范](开发与验收规范.md)：开发、实验、测试和材料编写必须遵守的统一规则。
4. [项目改造执行任务书](空域电波哨兵_项目改造任务书.docx)：8 个阶段、64 项任务的 Word 版 WBS。
5. [优化报告](优化报告.md)：现有原型已经完成的修复、可信度调整和测试结果。
6. [软件使用步骤](软件使用步骤.docx)：原型软件的历史操作说明，后续应随参赛版界面更新。
7. [轴承故障诊断启动清单](轴承故障诊断_启动清单.md)：第一阶段的独立 Conda 环境、CWRU 数据下载和可追溯验收清单。
8. [网上轴承模型对照记录](网上轴承模型对照记录.md)：网上候选项目、权重状态、兼容性和后续复现边界。
9. [CWRU 数据适配说明](轴承数据适配说明.md)：只读 MAT 信号加载、异常通道处理和固定窗口切片规则。

## 维护规则

- 产品定位、功能范围或算法主线发生变化时，先更新《项目说明》和《参赛改造方案》。
- 开发任务、里程碑或负责人发生变化时，更新 Word 任务书或另建项目看板，不在多个文档中重复维护进度。
- 任何准确率、时延、模型大小和开放集指标都必须来自可复现实验产物；演示数据不得用于声明业务效果。
- 对外提交前，统一执行匿名、版权、数据许可和原创边界检查。
