## 2. 范围边界

## 3. 建立独立 Conda 环境

### 3.1 环境位置

C 盘空间较少，使用固定的 E 盘路径：

```powershell
conda create --prefix E:\CondaEnvs\rofee-bearing python=3.10 -y
conda activate E:\CondaEnvs\rofee-bearing
python --version
```

验收：

- [ ] `python --version` 显示 Python 3.10.x。
- [ ] `where.exe python` 的第一条路径位于 `E:\CondaEnvs\rofee-bearing`。
- [ ] 不在 `base` 环境中安装本项目依赖。

### 3.2 安装 PyTorch 和项目依赖

1. 从 [PyTorch 官方安装选择器](https://pytorch.org/get-started/locally/) 获取当前稳定版命令，选择 `Windows / Pip / Python / CUDA`。
2. 不凭记忆固定某个 CUDA 版本；以执行当日官方选择器为准。
3. 安装现有软件运行依赖和训练辅助包：

```powershell
python -m pip install --upgrade pip
# 在此执行 PyTorch 官方选择器给出的命令
python -m pip install -r requirements-runtime.txt
python -m pip install pandas pyyaml tqdm pytest
python -m pip check
```

验收：

```powershell
python -c "import torch; print('torch=', torch.__version__); print('cuda=', torch.cuda.is_available()); print('gpu=', torch.cuda.get_device_name(0) if torch.cuda.is_available() else 'CPU')"
python -c "import numpy, scipy, pandas, sklearn, PyQt5, pyqtgraph; print('imports=ok')"
```

- [ ] `cuda=True`。
- [ ] GPU 名称包含 `RTX 4060 Laptop GPU`。
- [ ] `python -m pip check` 无冲突。
- [ ] 导入检查输出 `imports=ok`。

### 3.3 固化环境记录

在项目根目录生成：

```powershell
conda env export --prefix E:\CondaEnvs\rofee-bearing --from-history > environment-bearing.yml
python -m pip freeze > requirements-bearing-lock.txt
```

- [ ] `environment-bearing.yml` 不包含个人凭据或密钥。
- [ ] `requirements-bearing-lock.txt` 记录实际安装版本。

## 5. 下载 CWRU 首批数据

### 5.1 官方来源

- 数据总入口：<https://engineering.case.edu/bearingdatacenter/download-data-file>
- 正常基线：<https://engineering.case.edu/bearingdatacenter/normal-baseline-data>
- 12 kHz 驱动端故障：<https://engineering.case.edu/bearingdatacenter/12k-drive-end-bearing-fault-data>
- 试验装置与采集说明：<https://engineering.case.edu/bearingdatacenter/apparatus-and-procedures>
- 故障尺寸说明：<https://engineering.case.edu/bearingdatacenter/fault-specifications>

### 5.2 首批固定范围

只下载 12 kHz 数据，先统一使用驱动端振动信号 `DE_time`。

| 类别 | 故障直径 | 负载 | 数量 |
|---|---:|---|---:|
| 正常 `normal` | 无 | 0、1、2、3 HP | 4 |
| 内圈故障 `inner_race` | 0.007 英寸 | 0、1、2、3 HP | 4 |
| 滚珠故障 `ball` | 0.007 英寸 | 0、1、2、3 HP | 4 |
| 外圈故障 `outer_race_6` | 0.007 英寸，6点位 | 0、1、2、3 HP | 4 |

共 16 个官方 `.mat` 文件。本阶段不下载 48 kHz、风扇端、其他故障直径或其他外圈位置。

下载要求：

- [ ] 从官方页面的 `Normal_0` 至 `Normal_3` 获取 4 个正常文件。
- [ ] 从 0.007 英寸行获取 `IR007_0..3`、`B007_0..3`、`OR007@6_0..3`。
- [ ] 保留每个文件的官方下载 URL。
- [ ] 下载失败时不用第三方镜像替代；记录失败链接并报告。

## 6. 建立可追溯记录

`manifest.csv` 每个原始文件一行，至少包含：

```text
dataset,local_path,original_filename,class_name,fault_diameter_inch,
load_hp,rpm,sample_rate_hz,sensor_key,source_url,downloaded_at,sha256
```

约定：

- `dataset` 固定为 `CWRU`。
- `sample_rate_hz` 固定为 `12000`。
- `sensor_key` 记录实际 `.mat` 键名，其后缀应为 `DE_time`，不允许仅凭文件名猜测。
- `rpm` 以文件内字段或官方页面为准。
- `sha256` 用 `Get-FileHash -Algorithm SHA256` 计算。
- 时间使用带时区的 ISO 8601 格式。

`datasets/bearing/cwru/README.md` 记录：

- [ ] 数据集名称、官方页面、访问日期。
- [ ] 试验对象、采样率、传感器含义。
- [ ] 本次下载的 4 类及范围。
- [ ] 许可证或使用条款查找结果；不明确时写“未确认，原始数据不入库、不转发”。
- [ ] 明确写出：后续必须按原始记录/工况分组，不得将同一原始记录切片后随机分到训练集和测试集。

## 7. 最小数据检查

使用 `scipy.io.loadmat` 做只读检查，不生成处理后数据。

- [ ] 16 个文件都可被读取。
- [ ] 每个文件都能找到唯一的 `DE_time` 数组。
- [ ] `DE_time` 为数值型、非空、无 NaN/Inf。
- [ ] 为每个文件记录数组形状、最小值、最大值、均值和标准差。
- [ ] 检查结果保存为 `datasets/bearing/cwru/inspection.json`，不包含虚构数值。

可以为这个检查添加一个小型脚本和单元测试，但不在本阶段实现通用数据加载框架。

## 10. 停止条件

遇到以下情况时停止并报告，不自行扩大范围：

- 官方数据链接不可访问或文件内容与页面描述不符。
- PyTorch 无法识别 RTX 4060，且重新核对官方安装命令后仍失败。
- 需要覆盖原有模型、删除用户文件或大规模修改现有应用。
- 数据许可条款要求付费、登录授权或限制与当前用途冲突。
