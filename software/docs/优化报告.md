# 智能信号处理原型验证系统优化报告

> 文档性质：参赛改造前的历史基线记录。当前项目统一定位与后续方案分别以《项目说明》和《参赛改造方案》为准。

## 项目功能盘点

- 主页：加载 `.npy` 信号，显示时域、频谱和时频图，提取小波、双谱、J/R、HHT 特征。
- 信号识别：支持编码、通联、个体、调制、业务五类任务，包含单文件、多文件、批量目录识别、中间特征及 t-SNE 展示。
- 信号生成：使用条件 GAN 生成 15 类调制信号，保存 `.npy`，切换类别和样本并绘制 I/Q 波形。
- 网络轻量化：对比原始模型和轻量模型的精度、速度与参数量。

## 已完成优化

1. **程序可启动**：将 HHT 专用的 `pyhht/tftb` 改为可选依赖，未安装时不再阻塞整个应用；增加精简运行依赖清单。
2. **界面统一**：新增深色科研风格主题，统一页签、按钮、输入框、日志、分组框、滚动条和绘图区；增加最小窗口尺寸、输入校验、只读结果框与 CPU/GPU 状态栏。
3. **安全交互**：数据未加载时禁用识别/重绘按钮，生成目录未选择时禁用生成按钮；正确处理文件对话框取消操作，不再访问未初始化变量。
4. **绘图兼容**：时频图改用 pyqtgraph 原生图像项，适配新版 Matplotlib/NumPy；频谱使用界面采样率，不再硬编码 16000 Hz；修复常数数组归一化除零。
5. **主页特征**：重新连接小波、双谱、J/R、HHT 菜单动作；修复一维/二维信号选择、视区索引和 NumPy 2.x 移除 `np.mat` 后的双谱计算。
6. **识别模型**：验证五类识别权重均可加载；模型改为按需加载，切换任务时不再立即阻塞界面；修复个体识别同名模型实现匹配问题。
7. **GAN 生成**：生成器与识别模型状态分离，使用推理模式和 `no_grad`；真正保存到用户选择目录；修复类别/指定样本切换和越界校验。
8. **评分可信度**：删除“自身随机打乱后计算 FID”的无效实现；当前进一步改为按条件类别分别计算五项透明信号统计的批内偏离，只辅助定位同批次异常样本。界面明确它不验证类别、真实性或模型质量。真实 FID 仍需外部真实样本和固定特征提取器。

## 动态瀑布图专项说明

### 集成方案

- 使用 `scipy.signal.spectrogram` 计算逐帧时频功率，不在播放循环中创建 Matplotlib Figure/Axes。
- 使用 pyqtgraph `ImageItem` 原位更新历史矩阵，并固定相对 dB 色阶，避免不同帧因自动缩放产生明暗闪烁。
- 一维实信号显示 `0～Fs/2` 单边频谱；`(2, N)`、`(N, 2)`、复数 IQ 显示 `-Fs/2～Fs/2` 双边频谱；频率刻度由当前采样率动态生成。
- 单个带父对象的 `QTimer` 以约 30 FPS 驱动显示，使用真实经过时间批量追帧，兼顾高采样率播放进度与界面响应。
- 主页提供 FFT 点数、历史行数、播放速度、播放/暂停/继续/停止/重播和帧进度控件；离开主页自动暂停，切换到时域/静态时频图或关闭窗口时清理定时器和绘图状态。

### 未原样复制外部参考脚本的原因

老师提供的参考脚本适合作为效果原型，但存在不适合直接集成到长期运行桌面软件的问题，因此保留功能目标并重写实现：

- 刷新间隔换算少乘 `1000`，毫秒定时器会以错误速度运行。
- 第二个定时器没有可靠停止路径，窗口切换或关闭后仍可能继续回调。
- 已计算 dB 数据却混用线性功率进行显示，色阶语义不一致。
- 频率刻度固定为 `20 kHz～100 kHz`，不能随界面采样率变化。
- 二维数组和复数 IQ 信号的维度/频谱处理不正确。
- 播放过程中持续创建 Matplotlib 对象，容易累积内存和绘图资源。
- 每帧打印调试信息，会显著增加长信号播放开销并污染日志。

### 本轮正确性与生命周期修复

- 增加全零信号 dB floor，保证无能量输入保持最暗而不是被归一化为 `0 dB`。
- 对 NaN/Inf、短于 FFT 的信号和非法形状进行明确处理；只接受 `(N,)`、`(1,N)`、`(2,N)`、`(N,2)` 及复数一维信号。
- 主页使用独立的 `home_data/home_file`，不再被识别页共享数据覆盖；特征提取统一使用主页数据和安全的选区边界。
- 瀑布模式提取特征时暂停并使用整段主页信号，避免把 Hz 频率视区误当成采样点索引。
- 在时域、静态时频和瀑布模式之间切换时，清理 Y 轴倒置、自定义刻度、标题和图像项，防止坐标状态残留。
- 停止、播放完成、重复启动、切换页签和关闭窗口均统一清理或暂停定时器，避免孤立 QTimer 和重复信号连接。
